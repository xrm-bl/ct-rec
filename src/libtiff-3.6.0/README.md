# libtiff 3.6.0（旧版・保管）

このフォルダは、新しいlibtiffへ移行する前に使用していた **libtiff 3.6.0** の
ヘッダとコンパイル済み静的ライブラリを保管したものです。

| ファイル | 内容 |
|---|---|
| `tiff.h` | libtiff 3.6.0 のコアヘッダ（旧typedef `uint8`/`uint16`/`uint32` を定義） |
| `tiffio.h` | libtiff 3.6.0 の公開API ヘッダ |
| `tiffvers.h` | バージョン定義（`LIBTIFF, Version 3.6.0`） |
| `libtiff.lib` | x64 / MSVC 用のコンパイル済み静的ライブラリ |

## 用途
- ビルドの再現やロールバックが必要になった場合の参照用。
- 移行後の出力と旧版の出力を比較検証する際、旧バイナリを再ビルドするため。

## 注意
- 現行ビルド（`makefileCPU.bat` / `MakefileCPU` など）はこのフォルダを参照しません。
  新しいlibtiffのヘッダ/ライブラリは `src/` 直下に配置します。
- 3.6.0 のライブラリは4.x のオブジェクトとABI非互換です。混在リンク不可。
